## Обзор

Развитие искусственного общего интеллекта требует разработки механизмов самоанализа в многоагентных системах посредством генеративного бенчмаркинга. Данное исследование решает критическую задачу оценки качества моделей ИИ в граничных случаях, где сбои редки, но имеют серьёзные последствия. Двухэтапный конвейер генеративного бенчмаркинга синтезирует тестовые примеры, нацеленные на слабые места модели без участия человека, объединяя генетические алгоритмы для расширения плохо предсказываемых экземпляров с вариационными автокодировщиками для аппроксимации их распределения вероятностей. Методология формализует генерацию бенчмарков для задач регрессии и классификации, позволяя многоагентным системам проводить взаимную оценку через динамически генерируемые бенчмарки и облегчая самосовершенствование агентов посредством объективной оценки производительности.

## Содержание

Этот проект бенчмаркинга разрабатывает генеративную платформу для выявления и исправления сбоев моделей машинного обучения посредством синтетического расширения данных. Система обучает модели регрессии на данных о ценах на недвижимость, а затем использует двухэтапный конвейер, объединяющий генетические алгоритмы и вариационные автокодировщики для синтеза тестовых случаев, нацеленных на слабые места модели. Ключевые компоненты включают:

- **Предварительная обработка данных и инженерия признаков**: Модули, подготавливающие наборы данных московских квартир с кодированием признаков (MinMaxScaler, LabelEncoder, one-hot кодирование)
- **Модели регрессии**: Множественные реализации, включая KNN, Gradient Boosting, Random Forest, XGBoost и линейную регрессию для прогнозирования цен
- **Генерация сценариев с учётом справедливости**: Создание синтетических контрфактических примеров в подпространствах признаков с низкой производительностью
- **Вспомогательные утилиты**: 
  - Оптимизация гиперпараметров через Optuna
  - Анализ чувствительности через индексы Соболя
  - Дистилляция модели в нейронные сети
  - Разделение на обучающую и тестовую выборки и методы ансамбля

Посредством расширения обучающих данных алгоритмически генерируемыми примерами, которые выявляют ошибки предсказания, платформа повышает надёжность и справедливость модели по демографическим и географическим сегментам, позволяя автономным системам проводить самооценку и непрерывное совершенствование.

## Алгоритмы

Проект реализует двухэтапный конвейер генеративного бенчмаркинга, объединяющий генетические алгоритмы и вариационные автокодировщики:

1. **Генетические алгоритмы**: Выявляют и расширяют плохо предсказываемые экземпляры путём эволюции комбинаций признаков в направлении целевых улучшений производительности, руководствуясь коэффициентами линейной регрессии и индексами чувствительности Соболя
2. **Вариационные автокодировщики**: Изучают распределение вероятностей расширенных случаев сбоя, генерируя синтетические тестовые примеры, которые плотно заполняют области слабых мест модели
3. **Вспомогательные методы**: Кодирование признаков, разделение на обучающую и тестовую выборки, и ансамблевые модели регрессии (XGBoost, Random Forest, KNN)

Эти методы в совокупности позволяют автоматизировать обнаружение граничных случаев, где модели машинного обучения дают сбой, создавая реалистичные синтетические бенчмарки без ручной аннотации для непрерывной оценки и совершенствования модели.

## Установка

Установите Benchmarking одним из следующих способов:

**Сборка из исходного кода:**

1. Клонируйте репозиторий Benchmarking:
```bash
git clone https://github.com/DRMPN/Benchmarking
```

2. Перейдите в директорию проекта:
```bash
cd Benchmarking
```

3. Установите зависимости проекта:
```bash
pip install -r requirements.txt
```
