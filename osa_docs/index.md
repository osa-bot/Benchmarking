# Benchmarking Project

## Overview
This project is a machine learning benchmarking framework designed to preprocess, analyze, and evaluate apartment datasets with a focus on fairness considerations. The system handles data preparation, feature engineering, and model training pipelines, with particular emphasis on managing sensitive attributes alongside standard features.

## Purpose
The project aims to provide a comprehensive toolkit for building and evaluating machine learning models on apartment-related data while accounting for fairness constraints. It facilitates the separation of standard features from sensitive attributes, applies appropriate encoding and scaling transformations suitable for advanced models like Variational Autoencoders (VAE), and manages the complete workflow from raw data ingestion through model training and evaluation. The framework is structured to support benchmarking experiments that require careful handling of both predictive features and protected attributes in machine learning pipelines.
